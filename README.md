# Learn C++

A free, browser-based C++ learning platform with two structured paths: a beginner-friendly **Basic Course** and an **Advanced Course**.

## Features

- 10 beginner lessons covering the foundations of C++
- 10 advanced lessons covering modern C++ and software engineering
- Explanations, code examples, tips, and a knowledge check in every lesson
- Searchable lesson library
- Local progress tracking, completion status, and XP
- Responsive dark interface for desktop and mobile
- No account, backend, or build step required

## Getting started

Open `index.html` in a browser, or publish the repository with GitHub Pages.

1. Open **Settings → Pages** in the repository.
2. Select **Deploy from a branch**.
3. Choose the `main` branch and `/ (root)`.
4. Save. GitHub Pages will publish the site.

Progress is stored in the browser's local storage. It stays on the device and browser where it was earned.

## Learning paths

### Basic Course
Getting started, variables and data types, operators, conditions, loops, functions, arrays and strings, pointers and references, classes, and debugging.

### Advanced Course
Object-oriented design, RAII and smart pointers, move semantics, templates, the STL, lambdas, exceptions, concurrency, algorithms, modern C++, and build tooling.
